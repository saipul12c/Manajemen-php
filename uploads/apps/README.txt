Folder ini disiapkan untuk menampung file installer Android (.APK) jika Anda ingin menyediakan unduhan langsung file .apk ke siswa/guru:
- cbt-app.apk
- presensi-app.apk
- perpustakaan-app.apk

Jika file di atas diletakkan di folder ini, tombol 'Unduh File .APK' pada halaman utama dan apps.php akan otomatis aktif dengan ukuran file aktual.
